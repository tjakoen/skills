# Changelog

Every published version of the library, newest first. A version changes when the canon does: a new
standard, a removed one, or a change to a `when:` line that changes which task opens the skill.

## 1.0.0 — 2026-11-24

- First published tree: 29 skills, generated from the portfolio's `standards/`.
- The entry points: `main-flow`, `which-skill`, `glossary`.
- `skills.json` carries the machine-readable index.
